This entry draws a newspaper front page for Friday 20 November 2026, "THE WORLD IN ONE PICTURE", using only PIL shapes and text. It leads with the first Trump–Xi–Putin trilateral summit in Shenzhen, then Cyclone Akvan hitting India's east coast, the World Court's Myanmar/Rohingya ruling, and the Houthi strike on a Riyadh skyscraper, with a ticker of the day's other headlines. The image is generated deterministically by `draw_news.py` and copied to the output by `main.py`.

## Run it

```bash
python3 main.py
```

This copies the pre-rendered `entry.png` from the repo to the output directory (or `$MAKEFUN_OUTPUT_DIR`), verifies its SHA-256, and prints the digest.
